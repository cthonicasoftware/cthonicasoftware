Operating Model

The price line follows the handoff boundary.

Spend rises only when responsibility broadens: from one operator capturing safely, to a team reviewing evidence, to a program buying governance and deployment certainty.

Basic

Capture discipline for one active stream of work. It is the right entry point when the hardest problem is preserving the run.

Professional

Shared review, queries, and validation across a working team. It becomes valuable once release conversations need a common evidence surface.

Enterprise

Governance, procurement, and deployment terms built around program risk rather than a generic SaaS limit table.

Deployment Notes

Astrolabe stays low-friction. Orrery becomes the multiplier. Enterprise wraps the control plane around both.

  • Use Basic while collection is still being standardized.
  • Move to Professional when release review needs searchable manifests, validation output, and shared context.
  • Use Enterprise when hosting, security review, procurement, or support terms no longer fit a fixed public tier.
